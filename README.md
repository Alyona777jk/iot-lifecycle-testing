# Практична робота 8.2: Тестування та життєвий цикл IoT-продукту

## Опис проекту
Даний проект містить репозиторій для комплексного тестування, моніторингу та оцінки життєвого циклу віртуальної IoT-системи на базі openHAB (10+ віртуальних пристроїв).

## Структура репозиторію
- `openhab/conf/` — конфігурація пристроїв, правил, моніторингу та аномалій.
- `testing/` — тестові сценарії, симуляція збоїв та Python-скрипти для стрес-тестування.
- `ux_research/` — матеріали usability-тестування та відгуки користувачів.
- `docs/` — стратегія OTA-оновлень, KPI/метрики та Roadmap на 6 місяців.

## 🤖 Декларація використання ШІ

У відповідності до вимог академічної доброчесності, нижче наведено інформацію про використання інструментів штучного інтелекту під час виконання практичної роботи:

1. **Назва інструменту ШІ:** OpenAI ChatGPT / Claude / Gemini.
2. **Мета використання:** 
   - Генерація шаблонів конфігураційних файлів openHAB (`.items`, `.rules`).
   - Створення базового Python-скрипту для запусків стрес-тестування REST API.
   - Структурування документації для OTA-міграції та Roadmap.
3. **Текстовий запит (промпт):**
   > "Створи структуру файлів та конфігурацію openHAB для 10 віртуальних пристроїв, правила відстеження heartbeat, скрипт стрес-тестування на Python та документацію для життєвого циклу IoT продукту."
4. **Використані фрагменти згенерованого контенту:**
   - Шаблон структури Item-ів та базовий синтаксис OpenHAB Rules.
   - Скелет Python-скрипту з використанням бібліотеки `requests`.
5. **Опис власного доопрацювання:**
   - Перевірено та відкориговано назви атрибутів та типів пристроїв openHAB.
   - Додано реалістичні пороги аномалій (температура, рівень CO2) та тайм-аути офлайн статусу.
   - Оформлено фінальну структуру репозиторію та текстові звіти через CLI Git Bash.
