# Usability Testing & Feedback Analysis

## Target Group: 4 Users (Non-technical & Smart Home enthusiasts)

### Questionnaire Score Summary (1-5 Scale)
1. **Dashboard Readability:** 4.2 / 5.0
2. **Navigation Ease:** 3.8 / 5.0
3. **Alert Clarity:** 4.5 / 5.0

### Key UX Issues Identified
1. Sensor last-seen timestamp font size is too small on mobile screens.
2. Dark mode contrast for status badges (OFFLINE/ONLINE) needs higher visibility.
3. Too many manual steps required to add automation rules from the mobile web UI.
